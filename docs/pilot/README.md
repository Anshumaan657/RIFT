# RIFT V1 pilot packet

This directory contains the controlled design-partner pilot templates required by
Phase 9. It must contain only synthetic placeholders until a pilot is formally
authorized. Do not commit partner names, target hosts, tokens, evidence, or
private contact details.

## Required sequence

1. Select one design partner and obtain a signed authorization record.
2. Complete `preflight-checklist.md` for the staging target and testing window.
3. Run the assessment through the operator UI during the approved window.
4. Review every finding and export only a reviewed report.
5. Record sanitized metrics in `metrics.csv` and issues in `issue-log.md`.
6. Have the independent AppSec reviewer confirm the Phase 8 packet before any
   expansion beyond the first partner.

The first pilot is limited to one partner. Expand to at most five only after
resolving safety or reliability issues from the previous assessment.
